# Day 01 - Student Registration System

## Project Objective

Create a simple Python program that collects student information from the user and displays a formatted registration summary.

## Features

- Accepts student details from the user
- Stores information using variables
- Displays registration details in a structured format

## Concepts Learned

- Variables
- Data Types
- User Input
- Type Casting
- Print Statements
- f-Strings

## Technologies Used

- Python 3

## How to Run

1. Install Python 3
2. Open the terminal in this folder
3. Run the following command:

```bash
python student_registration.py
```

## Sample Input

```text
Student ID: 1
Student Name: Rani
Age: 15
Gender: Female
Standard: 10
Division: A
School Name: New High School
Mobile Number: 9876543210
City: Pune
```

## Sample Output

```text
======================================== 
REGISTRATION DETAILS 
========================================
Student ID      : 1
Student Name    : Rani
Age             : 15
Gender          : Female
Standard        : 10
Division        : A
School Name     : New High School
Mobile Number   : 9876543210
City            : Pune
==========================================
```
