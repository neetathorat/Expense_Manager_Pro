# Expense Manager Pro

## Overview

Expense Manager Pro is a Python-based expense management application built to manage and track personal expenses.

This project is developed step by step using real-world software development practices, focusing on clean code, problem-solving, and application design.

---

## Project Goal

The goal of this project is to build a complete expense management system while improving Python programming skills and learning real project development workflow.

---

## Current Version

Version: 0.1

---

## Features

### Completed:
- Project structure setup
- Menu-driven application
- Application heading with project name and version
- Add expense feature (basic)
- View expense option (basic)

### Planned:
- Store expenses permanently
- Expense history
- Expense categories
- Monthly expense summary
- Budget tracking
- Data analysis
- Error handling
- Object-Oriented Programming structure
- AI-based spending insights
